# UI overhaul, Phase 6 (sweep of the remaining pages): implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The pages the earlier phases didn't touch get the same look: card sections with an icon header, badges, icon buttons and even spacing. No flow changes.

**Architecture:**
- **Two primitives** in `src/ui/components/ui/`, both shown on `/#design`:
  - `Section`: a card with an optional icon, a title, a one-line description and header actions. It renders `<section aria-label={label ?? title}>`, so existing region names stay.
  - `Badge`: a tinted pill with `tone` = neutral, accent, success, warning, danger or info.
- **The pages are restyled in place.** Components keep their logic; only markup and classes change.

**Spec:** `docs/specs/2026-09-29-ui-overhaul-design.md`, "Phase 6: Sweep". Branch `ui/sweep` from `main`.

## What changes, page by page

1. **Details panel (Keymap tab).**
   - **Overview:** a "Details" Section with its hint. The shortcuts become a two-column list of `<kbd>` chips with labels, instead of a run-on sentence. Conditional layers becomes a Section.
   - **Key panel:** its header shows a mini keycap of the key's current label, then "Key 25 · BASE".
   - **Clipboard:** Copy, Cut and Paste become icon buttons with labels.
   - **Selection panel:** the same header style.
   - **Encoder panel:** a knob icon in the header.
2. **Keyboard page.** "This config", "Your own keyboard" and "Start a new config" become Sections with icons (keyboard, pencil and plus). "This config" shows name and key count as badges.
3. **Layout designer.** "Start from a template" and the selected-key box become Sections, replacing the fieldset legends on the border. "Save layout" becomes the page's primary action in the header.
4. **Hardware wizard.**
   - The stepper becomes numbered circles joined by a line. Done steps show a check, and the current step is lime.
   - "Split keyboard" becomes a Switch, and the Wiring fieldset becomes a segmented choice.
5. **Build & flash.** The connect, changes and build parts become Sections with icons. Status words (queued, running, success, failed) become Badges.
6. **Modules and Screens.** Their headers become Sections. Module categories become Badges. Screens drops its duplicate Build & flash button next to the top bar's.
7. **Help.** The nav highlights the section you're reading, using a scroll-spy like the palette's.

`VersionSelect` is a native select that Phase 1 already styled as a pill, so it's left as it is.
