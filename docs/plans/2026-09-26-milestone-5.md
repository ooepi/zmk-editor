| Module | Tags matching ZMK | Include | Adds |
| --- | --- | --- | --- |

A module follows the ZMK version: its west revision is the same tag. A module without a tag for the chosen version can't be added. Switching to that version lists the modules that block it.

## Core (`src/core`, test-first)

1. **`catalog/unicode.data.ts`** is generated by `scripts/gen-unicode.mjs` from zmk-unicode's language headers.
   `catalog/unicode.ts` adds lookup, search (by character, name or language), labels and the OS modes (`UC_MODE_*` / `UC_SET_*`).
2. **`catalog/modules.ts`** holds the module definitions: id, description, remote, supported ZMK versions, includes and behaviors.
   Module behaviors join the behavior catalog only when their module is installed. `&uc` gets a new `unicode` param kind that consumes one alias or two code points.
3. **`modules.ts`** (config level):
   - `installedModules`, `addModule` (west project + includes), `removeModule` (west project + includes; `&uc`/`&num_word` bindings become `&none`, and the count is reported);
   - `setZmkVersion`, which refuses when an installed module has no matching tag and says which;
   - `followZmkVersion(module)`, which clears a pinned revision.
4. **Unicode settings** — `getUnicodeMode` and `setUnicodeMode` read and write the `&uc { default-mode = <UC_MODE_…>; }` override. WinCompose is the module's default.
5. **Keycap labels** — `describeBinding` for `&uc`:
   - an alias or code points shows the character, with its shifted form as the sub label;
   - `UC_SET_*` shows the mode.

## UI

- **Modules tab** — a card per catalog module showing whether it's installed, which versions it supports, and add/remove. Installed modules not in the catalog are listed with their revision. Pinned revisions get a warning and a "Follow ZMK version" fix.
- **zmk-unicode card** — the OS mode (WinCompose, macOS, Linux, …) with short setup notes, and the Finnish/Swedish preset (ä, ö, å aliases shown first in the picker).
- **ZMK version** — a select in the top bar. Changing it checks module compatibility first.
- **Unicode picker** — in the binding editor for `&uc`: search, language chips, typing a character, and mode-switch keys.
- **Toolbar**:
  - "Open files" accepts any mix of `.keymap`, `.conf`, `west.yml` and `build.yaml`.
  - "Download config (.zip)" writes every generated file, using `fflate`.
